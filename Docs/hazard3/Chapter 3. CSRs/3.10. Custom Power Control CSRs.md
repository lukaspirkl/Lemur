## <span id="page-41-2"></span>**3.10. Custom Power Control CSRs**

## <span id="page-41-3"></span>**3.10.1. msleep**

Address: 0xbf0

M-mode sleep control register. Resets to all-zeroes.

| Bits | Name         | Description                                                                                                                                                              |
|------|--------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 31:3 | -            | RES0                                                                                                                                                                     |
| 2    | sleeponblock | Enter the deep sleep state on a h3.block instruction as well as a<br>standard wfi. If this bit is clear, a h3.block is always implemented as<br>a simple pipeline stall. |

| Bits | Name      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1    | powerdown | Release the external power request when going to sleep. The<br>function of this is platform-defined — it may do nothing, it may do<br>something simple like clock-gating the fabric, or it may be tied to<br>some complex system-level power controller.<br>When waking, the processor reasserts its external power-up request,<br>and will not fetch any instructions until the request is<br>acknowledged. This may add considerable latency to the wakeup. |
| 0    | deepsleep | Deassert the processor clock enable when entering the sleep state. If<br>a clock gate is instantiated, this allows most of the processor<br>(everything except the power state machine and the interrupt and                                                                                                                                                                                                                                                  |
|      |           | halt input registers) to be clock gated whilst asleep, which may<br>reduce the sleep current. This adds one cycle to the wakeup latency.                                                                                                                                                                                                                                                                                                                      |
