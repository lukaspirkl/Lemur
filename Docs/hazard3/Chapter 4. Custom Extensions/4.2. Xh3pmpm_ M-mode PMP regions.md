# <span id="page-43-2"></span> 4.2. Xh3pmpm: M-mode PMP regions

This extension adds a new M-mode CSR, [pmpcfgm0,](#page-41-1) which allows a PMP region to be enforced in M-mode without locking the region.

This is useful when the PMP is used for non-security-related purposes such as stack guarding, or trapping and emulation of peripheral accesses.
