# <span id="page-882-1"></span>**11.3. PIO Assembler (pioasm)**

The PIO Assembler parses a PIO source file and outputs the assembled version ready for inclusion in an RP2350 application. This includes C and C++ applications built against the SDK, and Python programs running on the RP2350 MicroPython port.

This section briefly introduces the directives and instructions that can be used in pioasm input. For a deeper discussion of how to use pioasm, how it is integrated into the SDK build system, extended features such as code pass through, and the various output formats it can produce, see [Raspberry Pi Pico-series C/C++ SDK.](https://datasheets.raspberrypi.com/pico/raspberry-pi-pico-c-sdk.pdf)
