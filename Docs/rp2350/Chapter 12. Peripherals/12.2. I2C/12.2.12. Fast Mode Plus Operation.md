# <span id="page-999-0"></span>**12.2.12. Fast Mode Plus Operation**

In fast mode plus, the DW_apb_i2c extends fast mode operation to be support speeds up to 1000 kb/s. To enable the DW_apb_i2c for fast mode plus operation, perform the following steps before initiating any data transfer:

- 1. Set ic_clk frequency greater than or equal to 32 MHz (refer to [Section 12.2.14.2.1](#page-1002-0)).
- 2. Program the [IC_CON](#page-1007-0) register [2:1] = 2'b10 for fast mode or fast mode plus.
- 3. Program [IC_FS_SCL_LCNT](#page-1014-0) and [IC_FS_SCL_HCNT](#page-1014-1) registers to meet the fast mode plus SCL (refer to [Section](#page-1000-0) [12.2.14\)](#page-1000-0).
- 4. Program the [IC_FS_SPKLEN](#page-1041-0) register to suppress the maximum spike of 50 ns.
- 5. Program the [IC_SDA_SETUP](#page-1038-0) register to meet the minimum data setup time (tSU; DAT).
