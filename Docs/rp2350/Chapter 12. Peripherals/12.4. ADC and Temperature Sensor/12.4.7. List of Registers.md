# <span id="page-1070-3"></span>**12.4.7. List of Registers**

The ADC registers start at a base address of 0x400a0000 (defined as [ADC_BASE](#page-31-1) in SDK).

<span id="page-1070-4"></span>*Table 1119. List of ADC registers*

<span id="page-1070-5"></span>

| Offset | Name   | Info                                                                                                                                                                                                                           |
|--------|--------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 0x00   | CS     | ADC Control and Status                                                                                                                                                                                                         |
| 0x04   | RESULT | Result of most recent ADC conversion                                                                                                                                                                                           |
| 0x08   | FCS    | FIFO control and status                                                                                                                                                                                                        |
| 0x0c   | FIFO   | Conversion result FIFO                                                                                                                                                                                                         |
| 0x10   | DIV    | Clock divider. If non-zero, CS_START_MANY will start<br>conversions<br>at regular intervals rather than back-to-back.<br>The divider is reset when either of these fields are written.<br>Total period is 1 + INT + FRAC / 256 |
| 0x14   | INTR   | Raw Interrupts                                                                                                                                                                                                                 |
| 0x18   | INTE   | Interrupt Enable                                                                                                                                                                                                               |
| 0x1c   | INTF   | Interrupt Force                                                                                                                                                                                                                |
| 0x20   | INTS   | Interrupt status after masking & forcing                                                                                                                                                                                       |

#### <span id="page-1072-0"></span>**[ADC:](#page-1070-5) DIV Register**

**Offset**: 0x10

#### **Description**

Clock divider. If non-zero, CS_START_MANY will start conversions

at regular intervals rather than back-to-back.

The divider is reset when either of these fields are written.

Total period is 1 + INT + FRAC / 256

*Table 1124. DIV Register*

<span id="page-1072-2"></span>

| Bits  | Description                                                      | Type | Reset  |
|-------|------------------------------------------------------------------|------|--------|
| 31:24 | Reserved.                                                        | -    | -      |
| 23:8  | INT: Integer part of clock divisor.                              | RW   | 0x0000 |
| 7:0   | FRAC: Fractional part of clock divisor. First-order delta-sigma. | RW   | 0x00   |
