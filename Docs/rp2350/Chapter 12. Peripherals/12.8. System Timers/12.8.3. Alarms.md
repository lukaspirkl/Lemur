#### <span id="page-1180-1"></span>**12.8.3. Alarms**

The timer has 4 alarms, and outputs a separate interrupt for each alarm. The alarms match on the lower 32 bits of the 64-bit counter, which means they can be fired at a maximum of 2<sup>32</sup> microseconds into the future. This is equivalent to:

- 2 <sup>32</sup> ÷ 10<sup>6</sup> : ~4295 seconds
- 4295 ÷ 60: ~72 minutes

# **NOTE**

This timer supports alarm intervals on the order of one microsecond to one hour. For a longer alarm, see [Section](#page-1194-0) [12.10](#page-1194-0).

To enable an alarm:

- 1. Enable the interrupt at the timer with a write to the appropriate alarm bit in [INTE](#page-1189-0) (e.g. (1 << 0) for [ALARM0](#page-1186-4)).
- 2. Enable the appropriate timer interrupt at the processor (see [Section 3.2](#page-82-0)).
- 3. Write the time you would like the interrupt to fire to [ALARM0](#page-1186-4) (i.e. the current value in [TIMERAWL](#page-1188-2) plus your desired alarm time in microseconds). Writing the time to the ALARM register sets the [ARMED](#page-1187-1) bit as a side effect.

Once the alarm has fired, the [ARMED](#page-1187-1) bit clears to 0. To clear the latched interrupt, write a 1 to the appropriate bit in [INTR](#page-1189-1).
