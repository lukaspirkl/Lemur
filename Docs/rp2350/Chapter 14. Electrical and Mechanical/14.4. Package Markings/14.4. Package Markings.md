# <span id="page-1327-0"></span>**14.4. Package Markings**

RP2350 comes in 7 × 7 mm QFN-60 and 10 × 10 mm QFN-80 packages which are marked with the following data:

- Pin 1 Dot
- Logo
- Part number
- Date code (Week)
- Silicon lot number
- Date code (Year)

Part number includes the following:

- Device name "RP2350"
- Package type, "A" for QFN-60 or "B" for QFN-80
- <span id="page-1327-1"></span>• Revision "0A2"
