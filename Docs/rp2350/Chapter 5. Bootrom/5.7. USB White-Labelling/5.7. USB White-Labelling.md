# <span id="page-410-0"></span>**5.7. USB White-Labelling**

To brand RP2350-based products, customers may replace identifying information exposed by USB interfaces. We call this **white-labelling**, and you can accomplish it in RP2350 by specifying values in OTP.

- 1. Write the OTP location of the white-label data structure via [USB_WHITE_LABEL_ADDR](#page-1313-0) (see that register description for the data structure contents).
- 2. Initialize the fields you wish to override in the white-label data structure and mark them valid.
- 3. Set [USB_BOOT_FLAGS.](#page-1311-1)WHITE_LABEL_ADDR_VALID to mark the white-labelling as valid.
