# <span id="page-439-4"></span>**6.1.3. Digital Core Supply (DVDD)**

The chip's core digital logic is powered by DVDD, which should be at a nominal 1.1 V. A dedicated on-chip core voltage regulator allows DVDD to be generated from a 2.7 V to 5.5 V input supply. See [Section 6.3](#page-446-0) for details. Alternatively, DVDD can be supplied directly from an off-chip power source.
