#### <span id="page-518-0"></span>**8.1.3. Frequency Counter**

The frequency counter measures the frequency of internal and external clocks by counting the clock edges seen over a test interval. The interval is defined by counting cycles of clk_ref, which must be driven either from XOSC or a stable external source of known frequency.

The user can pick between accuracy and test time using the [FC0_INTERVAL](#page-543-0) register. [Table 541, "Frequency Counter](#page-518-2) [Test Interval vs Accuracy"](#page-518-2) shows this trade off:

*Table 541. Frequency Counter Test Interval vs Accuracy*

<span id="page-518-2"></span>

| Interval Register | Test Interval | Accuracy |
|-------------------|---------------|----------|
| 0                 | 1μs           | 2048kHz  |
| 1                 | 2μs           | 1024kHz  |
| 2                 | 4μs           | 512kHz   |
| 3                 | 8μs           | 256kHz   |
| 4                 | 16μs          | 128kHz   |
| 5                 | 32μs          | 64kHz    |

| Interval Register | Test Interval | Accuracy |
|-------------------|---------------|----------|
| 6                 | 64μs          | 32kHz    |
| 7                 | 125μs         | 16kHz    |
| 8                 | 250μs         | 8kHz     |
| 9                 | 500μs         | 4kHz     |
| 10                | 1ms           | 2kHz     |
| 11                | 2ms           | 1kHz     |
| 12                | 4ms           | 500Hz    |
| 13                | 8ms           | 250Hz    |
| 14                | 16ms          | 125Hz    |
| 15                | 32ms          | 62.5Hz   |
