# <span id="page-554-1"></span>**8.2.4. Startup Delay**

The STARTUP_DELAY register specifies how many clock cycles must be seen from the crystal before it can be used. This is specified in multiples of 256. The SDK xosc_init function sets this value. The 1 ms default is sufficient for the RP2350 reference design (see [Hardware design with RP2350,](https://datasheets.raspberrypi.com/rp2350/hardware-design-with-rp2350.pdf) [Minimal Design Example](https://datasheets.raspberrypi.com/rp2350/hardware-design-with-rp2350.pdf#minimal-design-example)) which runs the XOSC at 12 MHz. When the timer expires, the STATUS_STABLE flag will be set to indicate the XOSC output can be used.
