# <span id="page-568-0"></span>**8.5.2. List of Registers**

The tick generator registers start at a base address of 0x40108000 (defined as [TICKS_BASE](#page-31-1) in SDK).

*Table 616. List of TICKS registers*

<span id="page-568-1"></span>

| Offset | Name            | Info                        |
|--------|-----------------|-----------------------------|
| 0x00   | PROC0_CTRL      | Controls the tick generator |
| 0x04   | PROC0_CYCLES    |                             |
| 0x08   | PROC0_COUNT     |                             |
| 0x0c   | PROC1_CTRL      | Controls the tick generator |
| 0x10   | PROC1_CYCLES    |                             |
| 0x14   | PROC1_COUNT     |                             |
| 0x18   | TIMER0_CTRL     | Controls the tick generator |
| 0x1c   | TIMER0_CYCLES   |                             |
| 0x20   | TIMER0_COUNT    |                             |
| 0x24   | TIMER1_CTRL     | Controls the tick generator |
| 0x28   | TIMER1_CYCLES   |                             |
| 0x2c   | TIMER1_COUNT    |                             |
| 0x30   | WATCHDOG_CTRL   | Controls the tick generator |
| 0x34   | WATCHDOG_CYCLES |                             |

| Offset | Name           | Info                        |
|--------|----------------|-----------------------------|
| 0x38   | WATCHDOG_COUNT |                             |
| 0x3c   | RISCV_CTRL     | Controls the tick generator |
| 0x40   | RISCV_CYCLES   |                             |
| 0x44   | RISCV_COUNT    |                             |

# <span id="page-569-0"></span>**[TICKS:](#page-568-1) PROC0_CTRL Register**

**Offset**: 0x00 **Description**

Controls the tick generator

*Table 617. PROC0_CTRL Register*

| Bits | Description                             | Type | Reset |
|------|-----------------------------------------|------|-------|
| 31:2 | Reserved.                               | -    | -     |
| 1    | RUNNING: Is the tick generator running? | RO   | -     |
| 0    | ENABLE: start / stop tick generation    | RW   | 0x0   |

# <span id="page-569-1"></span>**[TICKS:](#page-568-1) PROC0_CYCLES Register**

**Offset**: 0x04

*Table 618. PROC0_CYCLES Register*

| Bits | Description                                           | Type | Reset |
|------|-------------------------------------------------------|------|-------|
| 31:9 | Reserved.                                             | -    | -     |
| 8:0  | Total number of clk_tick cycles before the next tick. | RW   | 0x000 |
